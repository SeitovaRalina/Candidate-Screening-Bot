# Kickoff follow-up — сообщение для Антона (2026-09-04)

Я понял задачу так:

**Делаем:** Telegram-бот. На вход — резюме кандидата (текст или файл — уточняем ниже) + ссылка на вакансию (hh.ru, возможно другие источники). Бот сравнивает резюме с требованиями вакансии и выдаёт карточку кандидата.

**Результат (карточка кандидата):**
- Вердикт — подходит / не подходит, звать ли на тех. интервью.
- Green flags / red flags — что сработало в плюс и в минус, каждый пункт с цитатой из резюме (не «чёрный ящик»). Red flags включают и несоответствие вакансии, и признаки недостоверности (накрутка опыта, пересечение дат и т.п.).
- Рекомендации рекрутеру — какие вопросы задать на интервью.

**Процесс:** резюме → парсинг вакансии → сопоставление требований → проверка red flags → сборка карточки.

**Агент будет видеть:** резюме в присланном виде + содержимое вакансии по ссылке.

**Важное уточнение, которое нужно от вас:** вы упомянули, что нужно заходить в hh.ru под учёткой, чтобы видеть скрытые/прямые вакансии. Это означает работу под персональной авторизованной сессией — фиксируем это отдельным пунктом ниже, до реализации нужно подтверждение.

**Что бот делает сам:** парсит вакансию, сопоставляет с резюме, считает red flags, готовит черновик карточки.

**Что остаётся за человеком:** окончательное решение «звать / не звать» — бот выдаёт рекомендацию с обоснованием, а не автоматически отсеивает кандидата. Кадровое решение — зона человека по умолчанию; если вы хотите, чтобы бот отсеивал кандидатов автоматически, это отдельная договорённость с более высоким риском и её нужно проговорить явно.

**Проверяем на:** 5 реальных кандидатов (в т.ч. один с реальным red flag из вашей практики) — нужны от вас.

**В MVP входит:** резюме (формат уточняем) → вакансия по ссылке hh.ru (публичная, без логина) → карточка с вердиктом/green-red flags/вопросами для интервью, доставка в Telegram.

**В MVP пока НЕ входит (отдельно исследуем/оцениваем):** заход в hh.ru под личной учёткой для скрытых вакансий; вакансии не с hh.ru; массовая проверка (пакет резюме).

**Нужно от вас, чтобы стартовать сегодня:**
1. Резюме приходит файлом или текстом? Если файлом — какой формат (PDF / DOCX / скан)?
2. В MVP работаем только с публичными вакансиями hh.ru — ок? Если позже понадобятся скрытые — у компании есть официальный employer API / платный доступ к hh.ru, или речь только про личный логин сотрудника?
3. Бот должен работать без памяти между кандидатами — не хранить и не использовать данные предыдущих резюме при оценке следующего?
4. Сколько времени и где можно хранить резюме кандидата после обработки (это ПДн) — и есть ли ограничения на передачу резюме в сторонний LLM-сервис?

7. 5 реальных пар «резюме + вакансия» с известным вам правильным вердиктом (включая минимум 1 explicit red-flag случай).
8. Подтверждение: вердикт бота — рекомендация для рекрутера, финальное решение остаётся за человеком? (см. открытый вопрос выше)
